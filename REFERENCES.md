# References

This project is an independent clean-room implementation.

It was designed with architectural inspiration from:

- `cclank/lanshu-animated-architecture-diagram`
- `yizhiyanhua-ai/fireworks-tech-graph`

Motion design patterns were reviewed from open-source animation projects:

- `juliangarnier/anime`
- `maxwellito/vivus`
- `merri-ment/lazy-line-painter`
- `mojs/mojs`
- `motiondivision/motion`
- `airbnb/lottie-web`
- `veltman/flubber`
- `svgdotjs/svg.js`

These projects informed animation vocabulary only. Their source code,
documentation text, demos, and assets are not included.

No source code, documentation text, generated assets, sample images, default
specs, or repository history from those projects are included in this repository.

If future work imports or adapts any source code, documentation, or assets from
third-party projects, add the original license and copyright notice here before
shipping that change.
