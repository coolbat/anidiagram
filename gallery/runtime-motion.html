Change Control

Changes that alter visual timing, intensity, icon semantics, part IDs, stage effects, defaults, or runtime scheduling must be confirmed before implementation.

Allowed without confirmation: documentation-only typo fixes, test coverage that does not change runtime behavior, gallery regeneration from the same specs and runtime code.
